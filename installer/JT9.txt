Q65 / JT65 decoder (lib\jt9)
============================

RADIMCOM decodes Q65 and JT65 with jt9, the slow-mode decoder of WSJT-X, which runs as a separate program. RADIMCOM
records the USB audio of the VFO for a whole T/R period (15 to 300 s) from its UTC start, writes it as a WAV file
(12 kHz, 16 bit, mono) into data\q65, runs jt9 on it there and reads the decodes from its output. The WAV file is
deleted after the decoding; jt9 keeps its own small files there (decoded.txt, jt9_wisdom.dat, ...).

How it was built (MSYS2, "UCRT64" environment, gcc and gfortran 16.2): installer\build_jt9.sh
  The script checks out the folder lib of the WSJT-X tag, compiles the source lists of the CMakeLists.txt of WSJT-X
  (wsjt_FSRCS, wsjt_CSRCS and the CRC files of wsjt_CXXSRCS) into a static library and links jt9.f90 / jt9a.f90 with
  it, -static (one exe, no DLLs). lib/jplsubs.f is compiled with -std=f2018, so that gfortran 16 does not take its own
  subroutine SPLIT for the Fortran 2023 intrinsic of that name.

The source code of jt9 and of the libraries, in the exact versions used, is available on request (see NOTICE.md
of RADIMCOM).
