WSPR decoder (lib\wspr)
=======================

RADIMCOM decodes WSPR (Weak Signal Propagation Reporter, 2-minute cycles) with wsprd, which runs as a separate
program. RADIMCOM records 114 s of the USB audio of the VFO from each even UTC minute, writes it as a WAV file
(12 kHz, 16 bit, mono) into data\wspr, runs wsprd on it there and reads the decodes from its output. The WAV file
is deleted after the decoding.

How it was built (MSYS2, "UCRT64" environment, gcc and gfortran 16.2): installer\build_wspr.sh
  The script checks out only lib/wsprd of the WSJT-X tag, compiles wsprd.c and its helpers with gcc and
  indexx.f90 + osdwspr.f90 with gfortran, and links them with -static (one exe, no DLLs).

The source code of wsprd and of the libraries, in the exact versions used, is available on request (see NOTICE.md
of RADIMCOM).
